1. 引言与适用范围

本隐私政策（下称“本政策”）阐述了巴伯站（下称“我们”）在个人信息的收集、使用与披露方面的政策与程序。本政策适用于访问或使用我们任何相关服务（统称“本服务”）的所有个人（下称“您”或“用户”）。

我们的服务包括但不限于：

    我们在 BYOND 平台上的游戏服务器（下称“游戏”）。
    我们的官方网站、论坛、维基与状态页（统称“网站”）。
    我们的官方 Discord 服务器（下称“Discord”）。
    我们接入的应用程序编程接口（API），以及任何用于在这些平台之间连接、追踪或关联用户账户的其他后端服务。

访问或使用我们的任何服务，即表示您已理解并同意本隐私政策的条款。

2. 我们收集的信息

在运营本服务的过程中，我们可能会收集各类信息，包括：

    标识符与账户信息：包括您自愿提供的信息，例如您的 BYOND 用户名（CKey）、Discord 用户名与用户 ID，以及用于注册或访问本服务的任何其他凭据或标识符。
    设备与硬件信息：我们会自动收集您用于访问本服务的设备、计算机与软件的相关数据。这些数据可能包括但不限于您的 IP 地址、浏览器类型与版本、操作系统，以及唯一硬件标识符（例如 HWID）。
    服务使用与日志数据：当您与本服务交互时，我们的服务器会自动记录信息。这些数据可能包括连接时间戳、游戏内行为、聊天记录（来自游戏与 Discord）、IP 地址，以及您在我们网站上的活动记录。
    Cookie 与追踪技术：我们使用 Cookie、网络信标及类似追踪技术来收集您与我们网站交互的信息。这些信息用于网站的基本功能、会话管理以及保存您的偏好设置。其中可能包括用于存储您在我们网站或其他关联服务中登录状态的 Cookie。
    第三方平台数据：当您通过 BYOND 或 Discord 等第三方平台与本服务交互时，我们可能会收集这些平台作为其标准 API 或服务功能的一部分向我们提供的信息。
    出生日期：当您首次在我们的 Discord 上“接受认证审核”时，您需要以经过重度打码的身份证件形式向我们提供您的出生日期。

3. 数据使用的依据与目的

我们处理您的个人信息，是为了运营、维护与管理我们的社区及服务这一正当利益。我们不会将您的数据用于商业分析、营销，也不会将其出售给任何第三方。

我们使用您信息的目的如下：

    服务的提供与运营：运营、维护游戏、网站及所有关联服务，并提供其全部功能。
    账户管理与整合：创建并维护您的账户，并通过我们的 API 关联您的各类账户（BYOND、Discord 等），以实现社区功能的整合。
    安全、完整性与规则执行：保护我们的服务与社区的安全和完整性。
    法律合规：遵守任何适用的法律、法规或法律程序。
    年龄验证：鉴于本服务器的成人内容性质，确保巴伯站没有未成年人。

4. 数据共享与披露

我们不会出售、出租、租借或交易您的个人信息。仅在以下有限情形下，您的信息才会被披露：

    第三方服务提供商：您的信息必然会由您用于访问本服务的第三方平台（例如 BYOND 与 Discord）以及我们的基础设施提供商（例如我们的服务器或网站托管商）处理。我们无法控制这些第三方的隐私实践。
    经授权的志愿工作人员：我们经授权的志愿管理员与版主，仅在严格按照我们的内部政策履行管理与行政职责所必需时，才可能被授予访问您个人信息（例如日志、IP 地址与硬件标识符）的权限。
    法律合规与保护：如果我们善意地认为披露您的信息对于以下目的是必要的，我们可能会披露该信息：(a) 遵守法律义务；(b) 保护并捍卫我们的权利或财产；(c) 在紧急情况下保护用户或公众的人身安全；或 (d) 防范法律责任。

5. 数据存储与安全

我们实施合理的管理与技术安全措施，保护您的个人信息免遭未经授权的访问、使用或披露。我们将数据存储在安全的服务器上，这些服务器主要位于美国。然而，任何互联网传输方法或电子存储方法都无法做到 100% 安全。因此，我们无法保证其绝对安全。

6. 数据保留

我们会在实现信息收集目的及提供本服务所必需的期限内保留您的个人信息。

    与服务一般使用相关的信息（例如临时日志）可能会在有限期限内保留。
    与您账户资料相关的信息可能会在您的账户处于活跃状态期间保留。
    与管理、处罚、违规或执法行动相关的数据（包括 CKey、IP 地址与 HWID 等相关标识符）可能会被无限期保留。

7. 您的数据权利与选择

我们尊重您对自身数据的权利，包括 GDPR 等法规赋予的权利。在适用法律允许的范围内，您可能有权：

    访问权：请求获取我们所持有的关于您的个人信息的副本。
    更正权：请求更正不准确的个人信息。
    删除权（被遗忘权）：请求删除您的个人信息。

如何提出请求：

要行使上述任何权利，您必须通过政策页面底部指定的联系邮箱与我们联系。

限制：

    请求删除不可撤销，并将导致您的账户、游戏进度及相关数据被永久移除。
    对于过度重复、需要付出不成比例的技术努力或危及他人隐私的请求，我们可能会予以拒绝。
    对于法律要求我们保留的数据，我们无法满足删除请求。
    我们不会删除与管理及封禁记录相关的数据。

8. 儿童隐私

巴伯站禁止未成年人使用其平台。未满 18 岁者，以及未达到其访问巴伯站所在司法管辖区适用成年年龄者，均禁止使用巴伯站。如本隐私声明全文所述，部分用户可能会被要求向我们及我们的服务提供商提供一些信息，以便我们确认您已达到访问巴伯站所需的成年年龄。我们不会在知情的情况下处理未成年人的个人信息。如果您是向我们提供了个人信息的未成年人的父母或法定监护人，请通过 contact.bubberstation@gmail.com 与我们联系，以删除该未成年人的个人信息。

9. 本隐私政策的变更

我们保留随时修改本隐私政策的权利。任何变更都将发布在本页面上；对于任何重大变更，我们将通过在我们的网站或 Discord 上发布通知来告知您。在此类变更后您继续使用本服务，即构成您对修订后政策的接受。
